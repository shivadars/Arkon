WE1/WE2

Operating Table

A highly functional electric operating table with a powerful electro-mechanical motor system and modular design, supporting versatile positioning for diverse surgical disciplines.

  • Powerful electro-mechanical motor system ensures steady, sway-free positioning
  • Modular design with quick-plug connections for flexible configuration
  • Double Control System with override panel and hand remote
  • High-quality, moisture-proof melamine resin tabletop supports X-ray
  • Ultra-thin base with universal wheels and one-button emergency stop

Overview

WE1/WE2, a general operating table, supports various surgical applications. The high performance is based on a powerful electro-mechanical motor system. The operating table is steady and does not sway or move when the patient shifts positions. Modular design allows flexible positions and operations.

Key Features

Modular Design & Versatile Positioning

Allows for flexible configuration to meet diverse surgical requirements. Features a quick-plug connection for easy assembly of plates, and a kidney bridge that adjusts from 0 to 130 mm.

Double Control System

Equipped with an override control panel and a hand remote on standby. The override panel enables all movements in case of hand remote failure, ensuring uninterrupted operation.

Focusing on Details: Tabletop

The high-quality tabletop is made of melamine resin material that is moisture-proof, mildew-proof, easy to clean, and supports X-ray transmission. Optional carbon fiber bed plates are available.

Memory Foam Cushion

The top layer includes pressure-relieving memory foam that conforms to the patient's anatomy, increasing surface area and distributing weight to help prevent pressure ulcers.

Ultra-Thin Mobility Base

The base is ultra-thin and includes universal wheels, making movement convenient and labor-saving. Features a one-button emergency stop switch for rapid braking and easy C-arm access.
